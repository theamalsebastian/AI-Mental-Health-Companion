# 💙 AI Mental Health Companion

A Streamlit web app that helps users reflect on their emotions, analyze mood using sentiment analysis, and receive supportive coping suggestions.  
This project demonstrates **NLP, social impact, and web development skills**.

## ✨ Features
- 📝 Text input for daily reflections
- 🔍 Sentiment analysis using TextBlob
- 💡 Coping strategy suggestions (non-diagnostic)
- 📥 Downloadable daily reflection report
- 🌐 Deployed free on Streamlit Cloud
